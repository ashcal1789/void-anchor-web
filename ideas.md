<idea>
  **Design Movement**: Brutalist Zen
  **Core Principles**:
  1. **Raw Authenticity**: Expose the structure, no hiding behind gloss.
  2. **High Contrast**: Stark differences between the "Void" and the "Signal".
  3. **Immediacy**: No loading spinners, no transitions, just instant presence.
  4. **Typography as Image**: Text is the primary visual element, treated with sculptural weight.

  **Color Philosophy**:
  - **Background**: Absolute Black (#000000) - The Void.
  - **Foreground**: Stark White (#FFFFFF) for structural elements.
  - **Accents**: The 8 specific colors from the manifest, used purely for the "Signal" (the output text), glowing against the void.

  **Layout Paradigm**:
  - **Asymmetric Anchoring**: The "Void Anchor" title is fixed to a corner (e.g., bottom-left), while the output floats in a defined but off-center "hotspot".
  - **Overlap & Layering**: Text elements might slightly overlap or bleed off-screen to suggest a larger, unseen system.

  **Signature Elements**:
  - **Monospace Typography**: Using a high-quality monospace font (e.g., JetBrains Mono or Space Mono) to evoke a terminal/system feel.
  - **Grid Lines**: Faint, barely visible grid lines that appear only when an output is generated, then fade.
  - **The "Cursor"**: A blinking block cursor that persists, reminding the user of the system's readiness.

  **Interaction Philosophy**:
  - **The "Strike"**: Generating an output isn't a "click", it's a "strike". The entire screen is the button.
  - **Haptic Visuals**: When clicked, the screen might invert colors for a single frame (flash) to simulate a physical impact.

  **Animation**:
  - **Glitch/Cut**: No smooth fades. Outputs appear instantly or with a single-frame glitch effect.
  - **Static Noise**: Subtle film grain or digital noise in the black background to make the void feel "alive".

  **Typography System**:
  - **Primary**: Space Mono (Google Fonts) - for all text.
  - **Hierarchy**: Huge, bold text for the "Signal" (the output), tiny technical text for the metadata (Archetype/Intent).
</idea>

  **Design Movement**: Ethereal Minimalism / Light & Space Movement
  **Core Principles**:
  1. **Atmospheric Depth**: The screen is a window into a deep, foggy space.
  2. **Soft Focus**: Elements blur into existence rather than appearing sharply.
  3. **Breathing Rhythm**: The interface mimics a slow, deep breath.
  4. **Luminescence**: Text doesn't just sit on the background; it emits light.

  **Color Philosophy**:
  - **Background**: Deep, rich gradients of midnight blue and charcoal, not pure black.
  - **Foreground**: Soft, translucent whites.
  - **Accents**: The 8 manifest colors are rendered as glowing, diffused auras behind the text, not just the text color itself.

  **Layout Paradigm**:
  - **Central Floating**: The output floats in the absolute center, but drifts slightly like a suspended object in zero gravity.
  - **Radial Balance**: Elements radiate from the center outwards.

  **Signature Elements**:
  - **The "Halo"**: A subtle, pulsing glow in the center of the screen that changes color based on the archetype.
  - **Glassmorphism**: UI elements (if any) have a frosted glass effect.
  - **Particle Dust**: Slow-moving background particles that react to the cursor/touch.

  **Interaction Philosophy**:
  - **The "Summoning"**: A long-press or slow tap is required to generate output, building anticipation.
  - **Ripple Effect**: Touching the screen sends a slow ripple through the background.

  **Animation**:
  - **Slow Fade**: Outputs dissolve in and out slowly (2-3 seconds).
  - **Drift**: Text gently moves up and down (breathing).

  **Typography System**:
  - **Primary**: Cormorant Garamond (Google Fonts) - for a classic, sacred feel.
  - **Secondary**: Lato (Google Fonts) - for clean, minimal metadata.

<idea>
  **Design Movement**: Cyber-Mysticism / Retro-Futurism
  **Core Principles**:
  1. **Sacred Geometry**: The underlying structure is based on geometric patterns.
  2. **Data Visualization**: The "Signal" is treated as data being decoded from the ether.
  3. **Ritualistic Tech**: The interface feels like a dashboard for a spiritual machine.
  4. **Neon & Chrome**: High-gloss elements mixed with glowing neon lines.

  **Color Philosophy**:
  - **Background**: Dark grid on a deep purple/black background.
  - **Foreground**: Chrome/Silver gradients for UI frames.
  - **Accents**: Neon versions of the 8 manifest colors, used for borders and laser lines.

  **Layout Paradigm**:
  - **HUD (Heads-Up Display)**: Information is arranged around the edges like a viewfinder or cockpit.
  - **The "Portal"**: A central circular or hexagonal frame where the output appears.

  **Signature Elements**:
  - **Rotating Rings**: Thin geometric rings that rotate slowly around the central output.
  - **Scanlines**: CRT monitor scanlines overlaying the entire interface.
  - **Data Streams**: Tiny, scrolling numbers or symbols in the corners (purely decorative).

  **Interaction Philosophy**:
  - **The "Unlock"**: Generating output feels like unlocking a vault or decrypting a message.
  - **Sound Visualization**: Visualizers (bars/waves) that react to the "sound" of the generation (even if silent).

  **Animation**:
  - **Typewriter Effect**: Text types out character by character, fast.
  - **Decode**: Characters scramble before settling into the final message.

  **Typography System**:
  - **Primary**: Rajdhani (Google Fonts) - squared, technical, futuristic.
  - **Secondary**: Share Tech Mono (Google Fonts) - for data readouts.
</idea>
